## Claude Code specifics

- Start every task by creating a branch (AGENTS.md, git rule 1). If you find yourself on `main`
  with changes, stop and move them to a branch before committing.
- Before `gh pr create`, run the claims and the install check, and put what you tried in the PR
  body. Never mark your own PR approved or merge it.
- Ask before touching a folder another teammate owns.
